# Docs-Kavana

Ini adalah repositori terpusat untuk **Dokumentasi** seluruh proyek Kavana.
Fungsi utama dari direktori ini adalah:
1. Menyimpan semua file Markdown (`.md`) yang sebelumnya tersebar di berbagai repositori.
2. Memisahkan dokumentasi dari source-code untuk mempermudah manajemen pengetahuan (knowledge management) dan pencarian panduan.
3. Struktur di dalam folder ini mencerminkan asal repositori dokumen tersebut:
   - `Backend-Kavana/`: Dokumentasi API, database, dan proses bisnis.
   - `Frontend-Kavana/`: Dokumentasi UI/UX, Playwright reports, dan komponen.
   - `Infra-Kavana/`: Dokumentasi Docker, deployment, dan jaringan.
   - `Test-Kavana/`: Dokumentasi hasil QA, setup Selenium, dan laporan verifikasi.
